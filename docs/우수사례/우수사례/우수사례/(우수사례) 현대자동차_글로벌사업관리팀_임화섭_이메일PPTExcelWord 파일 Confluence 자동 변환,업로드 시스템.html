RAG 기반 가이드 서비스
구축된 지식베이스를 활용한 저연차 연구원 맞춤형 Q&A
PPT 데이터 구조화 및 추출 프롬프트 (Vision LLM용)
너는 차량 제어(VPC) 데이터 분석 전문가야. 첨부된 PPT 슬라이드에서 다음 정보를 추출하여 Markdown 형식으로 정리해줘. 시험 조건: 차량 모델, 외기온도, SOC 등 환경 변수 제어 파라미터: 수정 전(AS-IS)과 수정 후(TO-BE)의 수치를 테이블 형태로 정리 그래프 해석: 이미지 내 시계열 그래프의 추세(Peak 지점, 수렴 시간 등)를 텍스트로 기술 변경 근거: 슬라이드 내 'Note'나 '결론' 부분에서 최적화 이유를 'Rationale' 섹션에 작성 ⚠️ 에러 핸들링: - 슬라이드에 정보가 없거나 모호할 때는 "해당 내용이 없음"으로 표기 - 보고서 내부 데이터만 사용하고 외부 지식을 혼입하지 말 것
고연차 노하우(Insight) 정제 프롬프트
다음은 여러 건의 VPC 최적화 결과 보고서(md)들이야. 이 데이터들을 종합해서 '고연차 연구원의 판단 로직'을 추출해줘. · 특정 현상(예: 변속 충격, RPM 튐)이 발생했을 때 공통적으로 조정한 파라미터는? · 데이터 수치 변경 시 고려해야 할 트레이드오프(예: 응답성 vs 안정성) 관계를 설명해줘. 결과물은 '현상 - 원인 - 조치 - 주의사항' 구조의 가이드로 만들어줘.
저연차 연구원용 맞춤형 Q&A 프롬프트 (RAG 시스템용)
현재 [차종/조건]에서 [특정 현상]이 발생하고 있어. 과거 유사 사례에서 시니어 연구원들이 가장 먼저 확인했던 파라미터 3가지는 뭐야? 해당 데이터를 수정할 때 반드시 지켜야 할 기준(Constraint)은 무엇인지 알려줘. 분석 결과 보고서를 쓸 때 포함해야 할 필수 항목(Checklist)도 함께 제안해줘.
