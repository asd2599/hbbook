# M4 실습용 샘플 데이터 (교육용 Mock Data)

실제 사내 자료가 아닙니다. 가상의 지역본부·판매 실적입니다.

## 파일

| 파일 | 쓰이는 곳 |
|---|---|
| `월간KPI_2026_01-08.xlsx` | **M4-1 시연** — Excel에서 필터·정렬·차트를 직접 해 보이는 용도 |
| `월간KPI_2026_01-08.csv` | **실습 13 · 14** — 대시보드 1차 생성, 2차 개선 |
| `월간KPI_2026_09.csv` | **실습 15** — 다른 달 CSV 업로드 → AI 요약 |

xlsx와 csv는 **같은 데이터**입니다. M4-1에서 본 Excel이 실습 13의 CSV로 그대로 이어지도록 맞췄습니다.

## 열 구성

| 열 | 설명 |
|---|---|
| 연월 | `2026-01` ~ `2026-08` (9월 파일은 `2026-09`) |
| 지역본부 | 수도권 / 중부 / 영남 / 호남 |
| 매출(억원) | 월 매출 |
| 목표매출(억원) | 월 목표 |
| 달성률(%) | 매출 ÷ 목표 × 100 (소수 1자리) |
| 판매대수 | 대 |
| 신규고객수 | 명 |

- 8개월 × 4개 지역본부 = **32행** (9월 파일은 4행)
- 인코딩 **UTF-8 BOM** — Excel에서 바로 열어도 한글이 깨지지 않습니다
- 실습 13의 핵심 KPI 3개(매출·달성률·고객 수)가 모두 들어 있습니다
- 실습 14의 필터(분기별·팀별)를 만들 수 있도록 `연월`·`지역본부` 두 축을 넣었습니다

## 데이터에 심어둔 이야기

실습에서 "그래서 뭐가 보이나요?"를 물을 수 있도록 의도적으로 넣은 흐름입니다.

| 지역본부 | 흐름 |
|---|---|
| 수도권 | 규모가 가장 크지만 7~8월 목표 미달 (목표가 올라간 탓) |
| 중부 | 꾸준히 상승. 8월 달성률 **114.3%로 전체 최고** |
| 영남 | 변동이 큼. 2·5월 부진, 6~7월 회복 |
| 호남 | **6월 급락(달성률 71.6% — 전체 최저)** 후 8월까지 회복 중 |

**호남 6월 급락**이 M4-1·실습 14에서 "한눈에 보이는가"를 확인하기 좋은 지점입니다.
Excel 표로는 잘 안 보이지만 차트로 그리면 즉시 드러납니다 — M4-1 시연의 핵심 장면입니다.

### 9월 파일 (실습 15 — AI 요약용)

AI가 짚어낼 거리를 일부러 두 개 넣었습니다.

- **영남 급등** — 매출 1,610억, 달성률 132.0% (8개월 통틀어 최고)
- **호남 급락** — 매출 350억, 달성률 50.7% (회복하다 다시 무너짐)

실습 15의 "주요 변화 / 이상치 자동 요약"에서 AI가 이 둘을 잡아내는지 확인하면 됩니다.
못 잡아내면 요청에 "이상치를 짚어줘"를 넣어 다시 시켜 보십시오 — 프롬프트 차이를 보여주는 기회가 됩니다.

## 실패 대비

- CSV가 한글 깨져 보이면 → 메모장으로 열어 UTF-8로 다시 저장, 또는 xlsx를 대신 사용
- 대시보드가 안 만들어지면 → 완성본 대시보드를 배포해 실습 14부터 이어가기
