# 설문조사 샘플 데이터 3종 (교육용 Mock Data)

실제 사내 자료가 아닙니다. 가상의 팀·응답자·의견입니다.
공장명과 차종은 실제 명칭을 썼지만, 수치와 의견은 모두 지어낸 것입니다.

## 파일

| 파일 | 팀 | 응답 수 |
|---|---|---|
| `생산팀_작업환경설문.xlsx` | 생산 | 60명 |
| `설비팀_설비운영설문.xlsx` | 설비 | 50명 |
| `고객VOC팀_고객만족도설문.xlsx` | 고객VOC | 70건 |

각 파일은 시트 2개입니다 — **설문응답**(데이터) / **문항안내**(항목 설명).
문항안내 시트가 있어야 AI가 점수 의미를 제대로 해석합니다.

세 파일 모두 필터가 걸려 있고 첫 행이 고정돼 있어, Excel에서 바로 만져볼 수 있습니다.

## 1. 생산팀 — 작업환경 개선 설문

`응답ID / 응답일 / 공장 / 라인 / 직군 / 근속연수 / 작업환경만족 / 작업강도적정 / 안전관리만족 / 소통만족 / 개선우선순위 / 자유의견`

- 만족도는 1~5점. **작업강도적정은 점수가 낮을수록 "과중하다"** 는 뜻입니다 (문항안내 시트에 명시)
- 자유의견은 주관식이라 일부 응답자는 빈칸

**심어둔 이야기 — 의장3라인**

| 라인 | 작업강도적정 평균 |
|---|---|
| **의장3라인** | **1.3** |
| 프레스1라인 | 3.33 |
| 도장1라인 | 3.73 |
| 의장2라인 | 3.78 |
| 의장1라인 | 4.00 |
| 차체1라인 | 4.12 |

의장3라인 응답자 10명 중 대부분이 자유의견에 **"휴게시간"** 을 언급합니다.
전체 평균만 보면 3.35라 문제가 안 보이고, **라인별로 나눠야 드러납니다** — "쪼개서 보기"를 가르치기 좋은 지점입니다.

## 2. 설비팀 — 설비 운영·보전 설문

`응답ID / 응답일 / 공장 / 설비군 / 담당구분 / 고장대응만족 / 예방정비적정 / 부품수급만족 / 정비교육만족 / 월평균고장건수 / 개선요청분야 / 자유의견`

**심어둔 이야기 — 도장설비**

| 설비군 | 고장대응 | 부품수급 | 월평균 고장건수 |
|---|---|---|---|
| **도장설비** | **2.14** | **1.29** | **8.0** |
| 프레스설비 | 3.78 | 3.44 | 2.0 |
| 검사설비 | 3.89 | 3.22 | 2.0 |
| 물류자동화설비 | 4.17 | 3.75 | 2.2 |
| 차체용접설비 | 4.22 | 3.78 | 1.8 |

**만족도가 낮은 것과 고장이 잦은 것이 같은 설비**입니다.
"불만이 많다"가 아니라 **"불만에 이유가 있다"** 를 숫자로 확인하는 사례로 쓰시면 됩니다.

## 3. 고객VOC팀 — 고객 만족도 설문

`접수ID / 접수일 / 접수채널 / 차종 / 구입후개월 / 지역 / VOC유형 / 추천지수 / 재구매의향 / 처리상태 / 처리소요일 / 내용요약`

- 추천지수는 0~10점 (NPS 방식). 9~10 추천 · 7~8 중립 · 0~6 비추천
- 처리소요일은 **처리완료 건만** 기록 → 진행 중인 건은 빈칸입니다. **빈칸 처리를 다루기 좋습니다**

**심어둔 이야기 — 아이오닉5 / 인포테인먼트**

| 차종 | 추천지수 평균 |
|---|---|
| **아이오닉5** | **3.2** |
| 쏘나타 | 6.45 |
| 아반떼 · 싼타페 | 7.00 |
| 그랜저 | 7.23 |
| 투싼 | 7.29 |
| 팰리세이드 | 7.50 |

VOC 유형 중 **인포테인먼트가 19건으로 최다**이고, 그 대부분이 낮은 추천지수와 붙어 있습니다.
자유 텍스트(내용요약)에는 "재부팅 / 블루투스 끊김 / 음성인식" 같은 표현이 반복됩니다 —
**숫자와 텍스트를 함께 봐야 원인이 보이는** 구조로 만들었습니다.

## 실습에 쓰는 법

세 파일 모두 같은 흐름으로 쓸 수 있습니다.

1. **1차 요청** — `이 설문 결과를 정리해줘.` → 전체 평균만 나옴. 문제가 안 보임
2. **쪼개기** — `라인별로(설비군별로/차종별로) 나눠서 보여줘.` → **이상치가 드러남**
3. **텍스트까지** — `자유의견에서 반복되는 말을 찾아줘.` → 숫자의 이유가 나옴
4. **결론** — `팀장에게 보고할 3줄 요약을 만들어줘.`

2번에서 "어? 여기 이상한데"가 나오는 것이 이 데이터의 목적입니다.
**1번만 하고 끝내면 아무것도 안 보인다**는 것을 교육생이 직접 겪게 하십시오.

## 주의

공장명(울산·아산·전주)과 차종은 실제 명칭이지만 **수치·의견은 모두 가상**입니다.
교안이나 실습 화면에 띄울 때 **"교육용 예시 데이터"** 표기를 함께 노출해 주십시오.
각 파일 데이터 시트 하단과 문항안내 시트에도 같은 문구를 넣어 두었습니다.
