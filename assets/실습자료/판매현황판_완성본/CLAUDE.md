# 이 폴더의 목적

1. 판매실적 CSV 를 여러 개 올리면 합쳐서, 지역 × 차종별 달성률을 보여준다.
2. 기준을 벗어난 곳은 빨갛게 표시하고, AI 가 요약하고 질문에 답한다.
3. 달성률 계산과 주의 표시는 판매기준.md 를 따른다.

# 지켜야 할 규칙

1. AI 는 server.js 를 거쳐 부르고, API 키는 화면에서 받는다.
2. 새 프로그램은 설치하지 않는다.
3. 항상 가장 단순한 방법으로 만든다.
4. 한 번에 하나씩 만들고, 끝나면 멈춰서 내가 무엇을 확인하면 되는지 알려준다.
5. 화면은 app.html 하나로 만든다.
6. 달성률 · 증감률 계산은 화면이 하고, AI 에게는 설명만 맡긴다.
