# 이 폴더의 목적

1. VOC 접수 CSV 를 여러 개 올리면 합쳐서, 차종 × 유형별 주간 건수와 전주 대비 증감을 보여준다.
2. 기준을 벗어난 곳은 빨갛게 표시하고, AI 가 문의 원문을 읽어 긍정 · 부정으로 나누고 요약하고 질문에 답한다.
3. 건수 계산과 주의 표시는 VOC기준.md 를 따른다.

# 지켜야 할 규칙

1. AI 는 server.js 를 거쳐 부르고, API 키는 화면에서 받는다.
2. 새 프로그램은 설치하지 않는다.
3. 항상 가장 단순한 방법으로 만든다.
4. 한 번에 하나씩 만들고, 끝나면 멈춰서 내가 무엇을 확인하면 되는지 알려준다.
5. 화면은 app.html 하나로 만든다.
6. 건수는 화면이 세고, AI 에게는 문의 원문만 보낸다 — 고객명은 보내지 않는다.
