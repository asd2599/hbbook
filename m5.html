[실습] 무엇이든 설치할 수 있게 준비합니다

M5 · 실습

제한을 두지 않습니다 — 다만 사내망이라 되는지부터 물어보고 안 되면 풀어 줍니다.

① 먼저 — 쓸 수 있는 상태인지 물어봅니다

파이썬과 npm 을 쓸 수 있는 상태인지 확인해줘.

npm 은 작은 패키지 하나를 실제로 받아 봐서 사내망에서 되는지까지 봐줘.

② 안 된다고 하면 — 그대로 이어서 시킵니다

npm config set strict-ssl false 를 적용하고 다시 확인해줘.

그래도 안 되면 registry 를 사내 Nexus 로 바꿔줘 —

https://nexus.auto-hmg.io/repository/npm-group/

③ 파이썬이 없다고 하면 — 설치까지 시킵니다

파이썬이 없으면 관리자 권한 없이 되는 방법으로 설치하고 버전까지 확인해줘.

④ 기획서대로 목업을 만든 뒤, 볼 때 — 서버를 띄웁니다

이 폴더의 server.js 를 실행해서 중계 서버를 띄워줘.

꺼지지 않게 계속 띄워 두고, 터미널에 찍힌 주소를 브라우저까지 열어줘.

앞의 설정은 왜 하나

사내망은 바깥으로 나가는 통신을 한 번 열어 보고 다시 봉합니다. npm 은 그걸 가짜 인증서로 보고 거절합니다 — 그 검사를 끄는 것입니다.

뒤의 설정은 왜 하나

그래도 막히면, 바깥 저장소 대신 사내에 복제해 둔 저장소를 보게 합니다.

설치가 막히면

권한 때문에 안 깔릴 수도 있습니다. 그때는 “설치 없이 되는 방법으로 만들어줘” 라고 하면 됩니다.
